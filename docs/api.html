REST same-origin

Descoberta e leaderboard.

Em desenvolvimento local, a origem do jogo é http://localhost:8010. O cliente não recebe hosts da infraestrutura e só pode escolher realms presentes no catálogo.

GET/api/v1/health/live

Verificação mínima da API usada pelo proxy e pelo contêiner.

{
  "status": "ok"
}
GET/api/v1/networks

Catálogo público sanitizado. Campos podem ser adicionados sem aviso.

{
  "schema_version": 2,
  "default_realm_id": "regtest",
  "networks": [{
    "realm_id": "regtest",
    "network": "regtest",
    "display_name": "Regtest local",
    "status": "ready",
    "playable": true,
    "initial_block_download": false,
    "verification_progress": 1.0,
    "pruned": false
  }]
}
GET/api/v1/networks/{realm_id}/leaderboard

Retorna até dez recordes do realm selecionado.

{
  "realm_id": "regtest",
  "leaderboard": [
    {"username": "Miner_42", "score": 12500}
  ]
}
POST/api/v1/networks/{realm_id}/leaderboard

Atualiza o recorde se o score for maior que o valor persistido.

{
  "username": "Miner_42",
  "score": 12500
}

Limite conhecido

Score ainda não é autoritativo

O navegador calcula a pontuação. O leaderboard é demonstrativo e não deve representar competição, prêmio ou ativo financeiro.

Privacidade operacional

Detalhes internos fora do contrato

O portal público não divulga credenciais, topologia, nomes físicos de nós, namespaces Redis, Swagger ou o documento OpenAPI bruto.
