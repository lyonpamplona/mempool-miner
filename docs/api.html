01.REST same-origin

Em desenvolvimento local, a origem do jogo é http://localhost:8010. O cliente não recebe hosts da infraestrutura e só pode escolher realms presentes no catálogo.

GET/api/v1/health/live

Verificação mínima da API usada pelo proxy e pelo contêiner.

{
  "status": "ok"
}
GET/api/v1/networks

Catálogo público sanitizado. Campos podem ser adicionados sem aviso.

{
  "schema_version": 2,
  "default_realm_id": "regtest",
  "networks": [{
    "realm_id": "regtest",
    "network": "regtest",
    "display_name": "Regtest local",
    "status": "ready",
    "playable": true,
    "initial_block_download": false,
    "verification_progress": 1.0,
    "pruned": false
  }]
}
GET/api/v1/networks/{realm_id}/leaderboard

Retorna até dez recordes do realm selecionado.

{
  "realm_id": "regtest",
  "leaderboard": [
    {"username": "Miner_42", "score": 12500}
  ]
}
POST/api/v1/networks/{realm_id}/leaderboard

Atualiza o recorde se o score for maior que o valor persistido.

{
  "username": "Miner_42",
  "score": 12500
}

03.Power-ups e Economia

O preço é resolvido no backend. Saldo, inventário, contadores e idempotência são atualizados na mesma operação Redis.

GET/api/v1/networks/{realm_id}/powerups/{username}

Retorna inventário, definições, preços e limites diários do jogador.

{
  "inventory": {"scanner": 2},
  "daily_limit": {"per_powerup": 3, "global": 10, "global_remaining": 9}
}
POST/api/v1/networks/{realm_id}/powerups/buy

Compra uma unidade ou lote de 1–3 unidades. O cliente não envia preço.

{
  "username": "Miner_42",
  "powerup_id": "scanner",
  "quantity": 1,
  "tx_id": "buy-pu-scanner-001"
}

402 = saldo insuficiente · 409 = limite diário atingido · retry com o mesmo tx_id não cobra novamente.

POST/api/v1/networks/{realm_id}/powerups/activate

Consome uma unidade disponível e aplica o efeito na rodada.

{
  "username": "Miner_42",
  "powerup_id": "scanner"
}

04.Limites e Privacidade

LIMITE CONHECIDO
O navegador calcula a pontuação. O leaderboard é demonstrativo e não deve representar competição, prêmio ou ativo financeiro.
PRIVACIDADE OPERACIONAL
O portal público não divulga credenciais, topologia, nomes físicos de nós, namespaces Redis, Swagger ou o documento OpenAPI bruto.
