REST

Operação e leaderboard

GET/api/health

Verifica API e Redis.

{
  "status": "ok"
}
GET/api/leaderboard

Top 10 por recorde decrescente.

{
  "leaderboard": [
    {"username": "Miner_42", "score": 12500}
  ]
}
POST/api/leaderboard

Atualiza somente se score superar o recorde.

{
  "username": "Miner_42",
  "score": 12500
}
Validação

ScoreSubmit

username: 1–12, letras/números Unicode, hífen e sublinhado. score: inteiro de 0 a 2.147.483.647. Erros retornam HTTP 422.

Tempo real

WebSocket /ws/game

O servidor envia game_start e depois faz fan-out do canal Redis. O cliente não envia comandos nesta versão.

WSgame_start
{
  "action": "game_start",
  "network": "regtest",
  "game_mode": "mempool",
  "mempool_count": 0
}

Risco aberto

Sem autoridade de score

Validação limita formato e tamanho, mas não prova que o jogador ganhou a pontuação. Não exponha o ranking como competição ou ativo.

Compatibilidade

Evolução aditiva

Novos campos podem ser adicionados. Renomear action ou remover campos exige versão de protocolo, atualização do cliente e testes.
