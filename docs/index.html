01.Visão Geral

O Mempool Miner é um jogo de caça-palavras onde as palavras não são inventadas: elas nascem de transações reais da mempool Bitcoin. Cada transação que entra na rede vira uma palavra BIP39 (derivada do TXID), e o jogador tem um cronômetro para encontrá-las numa grade de letras.

03.Componentes com Fronteiras Claras

₿ BITCOIN CORE

Origem de transações e blocos; RPC e ZMQ permanecem na rede privada.

⚙ INGESTORES + API

Transformam eventos, aplicam isolamento por realm e entregam contratos sanitizados.

▦ REDIS

Estado efêmero, fan-out e ranking; não possui porta publicada no host.

◈ PWA DO JOGO

Shell instalável, mobile-first e same-origin, sem armazenar respostas da API no cache offline.

05.Limites do Produto

INTEGRAÇÃO REAL
Transações, blocos, TXID, vsize e taxas vêm da infraestrutura configurada para cada realm.
ECONOMIA SIMULADA
Saldo, recompensa, hardware, mineração e Lightning são apenas mecânicas educacionais do jogo. Sem fundos reais, sem carteiras, sem hashrate real.
