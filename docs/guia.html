Guia Completo do Mempool Miner

Jogo educacional em tempo real que transforma transacoes reais do Bitcoin em palavras dentro de uma grade de caca-palavras.

O que e o Mempool Miner?

O Mempool Miner e um jogo educacional que conecta o mundo real do Bitcoin a experiencia interativa de um caca-palavras. Ele monitora transacoes reais da rede Bitcoin (Regtest, Signet ou Mainnet) e transforma cada transacao em uma palavra derivada do padrao BIP39, criando uma grade dinamica onde o jogador precisa encontrar as palavras antes que um novo bloco seja minerado.

Conceito central

Transacao Bitcoin → TXID → Hash SHA-256 → 128 bits → Palavra BIP39 → Grade

Cada transacao que entra no mempool do Bitcoin Core e convertida em uma palavra unica. Quando 6 palavras diferentes sao coletadas, uma nova rodada de caca-palavras e iniciada. O jogador tem ate o proximo bloco para encontrar todas as palavras.

O que o jogo NAO faz

  • Nao minera Bitcoin real
  • Nao abre canais Lightning
  • Nao movimenta fundos reais
  • Nao conecta carteiras
  • Nao calcula hashrate real

Sats, hashrate, carteira, recompensas e modo L2 sao mecanicas simuladas para fins educacionais e de entretenimento.

Componentes do sistema

Componente Responsabilidade
Bitcoin Core Nao Bitcoin que publica transacoes e blocos via ZMQ; fornece metadados via RPC
Ingestor Processo singleton por rede que consome ZMQ, calcula palavras e publica eventos
Redis Pub/Sub para eventos, estado dos nos, leaderboard e deduplicacao
FastAPI API REST e WebSocket que entrega dados ao frontend
Nginx Proxy same-origin que serve o frontend e redireciona para a API
Frontend Interface PWA com grade, cronometro, loja simulada e controles

Instalacao e execucao

Pre-requisitos

  • Docker Engine ou Docker Desktop com Compose 2.33.1+
  • 4 GB de RAM livres (Regtest + Signet)
  • Porta 8010 disponivel (jogo)
  • Porta 8020 disponivel (documentacao, opcional)

Instalacao rapida

# 1. Clone o repositorio
git clone https://github.com/seu-usuario/mempool.miner.git
cd mempool.miner

# 2. Copie o arquivo de configuracao
cp .env.example .env

# 3. Edite .env e substitua as senhas RPC de exemplo
#    (IMPORTANTE: use senhas fortes e aleatorias)

# 4. Valide a configuracao
docker compose config --quiet

# 5. Inicie o sistema
docker compose up -d --build

# 6. Verifique os servicos
docker compose ps

Acessando o jogo

  • Jogo: http://localhost:8010
  • Documentacao: http://localhost:8020/ (opcional)
  • API publica: http://localhost:8020/api/ (opcional)

Instalando como PWA

No navegador, clique no botao "Instalar app" para instalar o jogo como Progressive Web App. O service worker mantem apenas o shell estatico em cache; API, WebSocket, health e leaderboard nunca sao armazenados offline.

Mecanicas do jogo

Objetivo

Encontrar 6 palavras escondidas em uma grade de caca-palavras antes que:

  • O tempo acabe (20, 60 ou 75 segundos, dependendo da grade)
  • Um novo bloco seja minerado na rede Bitcoin

Fluxo de jogo

┌─────────────────────────────────────────────────────────────────┐
│                    CICLO DE JOGO                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. Coleta de palavras                                          │
│     → Transacoes chegam via WebSocket                           │
│     → Cada transacao vira uma palavra BIP39                     │
│     → 6 palavras unicas = nova rodada                           │
│     ↓                                                           │
│  2. Construcao da grade                                         │
│     → Grade 8×8 (modo L2), 12×12 (padrao) ou 15×15 (vsize alto)│
│     → Palavras posicionadas sem sobreposicao                    │
│     → Espacos preenchidos com letras aleatorias                 │
│     ↓                                                           │
│  3. Rodada ativa                                                │
│     → Cronometro inicia                                         │
│     → Jogador seleciona palavras na grade                       │
│     → Pontos calculados por palavra encontrada                  │
│     ↓                                                           │
│  4. Fim da rodada                                               │
│     → Vitoria: todas as palavras encontradas                    │
│     → Derrota: tempo esgotado ou novo bloco minerado            │
│     ↓                                                           │
│  5. Nova coleta                                                 │
│     → Buffer limpo, espera proximas transacoes                  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

Selecao de palavras

  • Mouse/Toque: Clique na primeira letra, arraste ate a ultima
  • Teclado: Use as setas para navegar, Enter para confirmar
  • Direcoes: Horizontal, vertical e diagonal (ambos os sentidos)

Pontuacao

pontos = (500 + comprimento × 50) × combo
Fator Valor
Base por palavra 500 pontos
Bonus por letra 50 pontos × comprimento
Combo Cresce 0.5x por acerto em menos de 8s (max 4x)

Multiplicadores especiais

Multiplicador Valor Condicao
Taxa alta ×3 Transacao com taxa acima de 20 sats/vB
Hash dourado ×5 TXID comeca com "00"
Modo Lightning ×10 Modo L2 ativado na loja

Mecanicas in-game

Loja de upgrades

A loja oferece 3 tipos de upgrades simulados:

1. Dica (Hint)

  • Custo: 5.000 sats ficticios
  • Efeito: Destaca a primeira celula de uma palavra nao encontrada
  • Uso: Apenas durante a rodada ativa

2. Hardware (Minerador)

  • Custo: Progressivo (100k, 500k, 2M sats)
  • Efeito: Adiciona +10 sats ao saldo por transacao processada
  • Niveis: 3 niveis disponiveis (CPU Miner → GPU Rig → ASIC Antminer)

3. Modo Lightning (L2)

  • Custo: 1.000.000 sats ficticios
  • Efeito: Muda o tema visual para azul Lightning, grade reduzida para 8×8, multiplicador ×10 em todas as palavras
  • Restricao: So pode ser ativado entre rodadas

Estados da rede

Estado Significado Acao do jogo
starting Servico iniciando Aguarda
syncing Na sincronizando (IBD) Nao inicia partidas
ready Realm disponivel Jogo ativo
disabled Profile nao iniciado Nao aparece no seletor
unavailable Heartbeat indisponivel Retorna ao seletor
stopped Ingestor encerrado Retorna ao seletor

Troca de rede

Ao trocar de rede (Regtest → Signet → Mainnet):

  1. A sessao atual e invalidada
  2. WebSocket e fechado
  3. Todos os timeouts e intervals sao cancelados
  4. Saldo e upgrades nao atravessam realms
  5. Nova conexao e estabelecida com o realm selecionado

GET /api/v1/networks/{realm_id}/leaderboard

Lista os 10 maiores recordes de uma rede.

{
  "realm_id": "regtest",
  "leaderboard": [
    {"username": "Miner_42", "score": 12500}
  ]
}

POST /api/v1/networks/{realm_id}/leaderboard

Envia uma pontuacao para o leaderboard.

{"username": "Miner_42", "score": 12500}

Regras:

  • Nickname: 1-12 caracteres (letras, numeros, hifen, sublinhado)
  • Score: inteiro entre 0 e 2.147.483.647
  • Apenas o maior valor e mantido

Perguntas frequentes

O jogo minera Bitcoin real?

Nao. O Mempool Miner e um jogo educacional que simula mecanicas de mineracao. Nenhuma transacao real e enviada, nenhum hashrate e calculado e nenhum Bitcoin e minerado.

Por que nao ha transacoes aparecendo?

Verifique se:

  1. O Bitcoin Core esta sincronizado (playable: true)
  2. Transacoes estao sendo enviadas ao mempool (em Regtest, use generatetoaddress ou envie transacoes)
  3. O ingestor esta rodando (docker compose ps)
  4. O WebSocket esta conectado (console do navegador)

Como gerar transacoes em Regtest?

# Obter endereco
docker compose exec bitcoin-regtest bitcoin-cli getnewaddress

# Enviar transacao
docker compose exec bitcoin-regtest bitcoin-cli sendtoaddress <endereco> 0.01

# Gerar bloco (para minerar transacoes pendentes)
docker compose exec bitcoin-regtest bitcoin-cli generatetoaddress 1 <endereco>

O leaderboard e persistente?

Sim, os recordes sao armazenados no Redis. Para resetar:

docker compose exec redis redis-cli FLUSHALL

Como instalar como PWA?

No navegador (Chrome, Edge, Firefox), clique no icone de instalacao na barra de endereco ou no botao "Instalar app" dentro do jogo.

O jogo funciona offline?

O shell do jogo (HTML, CSS, JS) e cacheado pelo service worker, mas as transacoes e eventos requerem conexao com a API. Offline, o jogo mostra uma mensagem indicando que a conexao e necessaria.

Posso usar minha propria carteira?

Nao. O jogo nao se conecta a carteiras externas. Sats, hashrate e recompensas sao simulados internamente.
