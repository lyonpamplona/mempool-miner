## 2. Lições Extraídas: Como Criar Paletas Pixel Art

### Princípios Fundamentais

1. **Valor antes de matiz (Value is King)**
   - A propriedade mais importante é o VALOR (claro/escuro), não o matiz
   - Uma paleta forte tem pelo menos: um preto, um branco e 2-3 tons médios
   - Se a arte é legível em escala de cinza, os valores estão corretos

2. **Paleta limitada = consistência**
   - 4-8 cores centrais é o ponto ideal para UI
   - 5 cores práticas: fundo, superfície, texto e 2 acentos
   - Menos cores = hierarquia visual mais clara

3. **Hue Shifting (Deslocamento de matiz)**
   - Sombras tendem a tons mais frios (azul/violeta)
   - Destaques tendem a tons mais quentes (amarelo/laranja)
   - Cria profundidade perceptiva sem adicionar mais cores

4. **Regra 60-30-10**
   - 60% cor dominante (fundo/superfície)
   - 30% cor secundária (elementos de UI)
   - 10% cor de acento (CTAs, alertas, destaques)

5. **Contraste simultâneo**
   - Cores parecem diferentes dependendo do que as rodeia
   - Nunca avalie uma cor isoladamente — teste no contexto real
   - Cinza médio em fundo escuro parece claro; no fundo branco parece escuro

6. **Um complemento como acento**
   - Uma cor do lado oposto da roda de cores cria "pop" visual
   - Laranja e azul, vermelho e verde, amarelo e violeta
   - Use o complemento com parcimônia como acento

### Erros Comuns a Evitar

- **Sem spread de valor:** Todas as cores com valor similar = aparência plana
- **Síndrome do arco-íris:** Usar todos os matizes com peso igual destrói coesão
- **Sombras super-saturadas:** Sombras devem ser mais frias e dessaturadas
- **Muddy mid-tones:** Misturar quente e frio na mesma intensidade = lama

```css
  color: var(--bg-primary);

.badge-error {
  background: var(--error);
  color: var(--text-primary);
}
```

### Elementos Pixel Art na UI

1. **Sem border-radius** — Cantos retos reforçam o estilo pixel art
2. **Fontes pixel/monospace** — Press Start 2P, VT323, Share Tech Mono
3. **Bordas grossas** — 2-4px solid, sem sombras suaves
4. **Ícones pixel** — Usar sprites 16x16 ou 32x32
5. **Efeitos de scanline** — Overlay sutil para efeito CRT
6. **Animações discretas** — Transições em steps, não smooth

## 5. Resumo Executivo

Para o Mempool Miner, a recomendação é:

1. **Usar o Bitcoin Orange `#f7931a` como cor de marca principal** — é reconhecível e conecta ao tema
2. **Fundo escuro `#0b0f1a`** — dark mode nativo, estilo terminal/retro
3. **10 cores no máximo** — mantém a estética pixel art e a consistência
4. **Sem border-radius** — cantos retos são essenciais para o visual pixel
5. **Fontes monospace/pixel** — reforçam a estética retro
6. **Ciano `#22d3ee` como acento neon** — contraste com o laranja Bitcoin
7. **Âmbar `#ffb703` para métricas** — conecta ao conceito de "ouro digital"

A paleta combina a identidade Bitcoin com a estética retro/8-bit, criando uma interface que é ao mesmo tempo funcional (dashboard de mineração) e tematicamente coerente (pixel art + blockchain).
