# Código de conduta

Este projeto espera colaboração respeitosa, técnica e inclusiva.

São bem-vindas críticas objetivas ao código, perguntas de iniciantes e
discordâncias fundamentadas. Não são aceitos assédio, discriminação,
humilhação, exposição de dados pessoais ou publicação deliberada de segredos.

Ao relatar um problema:

- descreva fatos observáveis e contexto;
- critique a implementação, não a pessoa;
- evite linguagem hostil;
- respeite divulgações privadas de segurança.

Mantenedores podem editar ou remover conteúdo incompatível com estas regras e,
em casos recorrentes, restringir a participação. Incidentes devem ser
encaminhados pelo mesmo canal privado indicado em SECURITY.md.
